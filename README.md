### Programs Included

**Q1 – Precedence, Associativity and Discount Calculation**
- Demonstrates operator precedence and associativity.
- Calculates gross amount, discount, GST and net amount.
- Explains undefined behaviour in increment operations.

**Q2 – Short-Circuit Evaluation**
- Demonstrates logical AND (&&) and logical OR (||).
- Compares logical operators with bitwise operators.
- Counts function calls using different condition orders.

**Q3 – Bitwise Operators**
- Uses bitwise AND, OR, XOR, NOT and shift operators.
- Switches devices ON and OFF.
- Toggles device states and checks device status.

**Q4 – Else-If Ladder and Switch**
- Implements a grade calculation system.
- Uses switch statements to assign grades.
- Tests valid marks and invalid marks.

**Q5 – Loop and Prime Number Checking**
- Checks whether a number is prime.
- Uses a for loop and break condition.
- Counts the number of divisions performed.

**Q6 – Loan Repayment Schedule**
- Calculates monthly loan interest and repayment.
- Uses a while loop.
- Displays the repayment schedule and total interest.
- Includes a safety limit to prevent infinite execution.

**Q7 – Diagnose, Redesign and Validate**
- Compares basic and improved prime-checking algorithms.
- Reduces unnecessary division operations.
- Measures and compares performance.
